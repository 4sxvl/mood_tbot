# Mood Telegram Bot

Telegram-бот для ведения дневника эмоций.

Бот помогает пользователю каждый день заполнить короткую анкету о настроении, энергии, эмоциях, факторах дня и комментариях.
Также бот может показывать список психологических практик и предлагать практики после заполнения дневника, если настроение было сниженным.

## Возможности

- заполнение дневника эмоций через Telegram
- список психологических практик

## Установка

Установить зависимости через `uv`:

```bash
uv sync
```

## Настройка окружения

Создать файл `.env` в корне проекта:

```env
BOT_TOKEN=your_telegram_bot_token
BOT_PROXY=your_telegram_proxy
G_CREDS_PATH=path/to/creds.json
G_SPREAD_KEY=your_google_spreadsheet_key
ADMIN_TG_IDS=[123456789,987654321]
```

## Инициализация базы данных

База данных используется через SQLite.

Создать таблицы:

```bash
uv run python -m app.scripts.init_db
```

Заполнить базу начальными практиками:

```bash
uv run python -m app.scripts.seed_practices
```

## Запуск бота

```bash
uv run python -m app.main
```

## Основные команды

```text
/start — запуск бота
/mood — заполнить дневник эмоций
/practices — посмотреть список практик
/daily_questions — меню управления вопросами дня (только для админов)
/help — помощь
```

## Примечание

SQLite-база создаётся локально в файле проекта.
